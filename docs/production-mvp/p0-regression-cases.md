# P0 回归样例与验收方法

状态：样例和检查方法已准备；本文不代表真实模型验收通过。用户的代表剧本由用户自行上传，不以本虚构短样本替代。

## 虚构对白样例

输入：[p0-dialogue-fixture.txt](fixtures/p0-dialogue-fixture.txt)。含两个人物、旧钥匙及两个地点，保留傍晚到夜晚的时间变化；没有外部旁白。用于用户需要小样时选择，不自动上传、不自动调用模型。

项目使用 screenplay / drama / reference_video。模型从设置页的实际默认值或项目覆盖取得；时长、参考图数量、原生音频与价格取本次运行解析结果，不把 H3 目录快照当作账户实测。

| 检查点 | 预期结果 | 证据 |
| --- | --- | --- |
| 导入 | 原始文件全文保留、编码正常，作为所选单集原文 | 项目/稳定集 ID、上传记录 |
| 规划 | 三场按地点或时间变化分别处理，不能把第二场、第三场合成同一单元；场内可按实际时长继续拆分 | 规划版本与原文范围 |
| 台词 | 林舟、许晴的六轮发言逐字保留，归属正确，不添加人物台词或画外音 | 逐条与原文对照 |
| 资产 | 两个人物和旧钥匙身份稳定；书店内外按用户确认登记或复用，不能默认把不同视角合并 | 新增/复用/衍生决定与依据 |
| 内容确认 | 沿用原内容确认和资产登记服务；确认前不自动进行视觉编写 | 确认记录、正式脚本 |
| 资产图 | 生成或上传可用资产图；同一钥匙材质与划痕一致 | 选中版本、人物外观审查 |
| 报价 | 显示目标集合、编排/申请时长、模型、分辨率、估算与币种；缺价显示未知 | 批次预览、实际提交选项 |
| 视频 | 人物交接钥匙、进店、离店的动作与顺序可辨认；对白正确、可听，人物外观基本一致 | 样片及人工结论 |
| 恢复 | 页面关闭和重连查询同一 batch/job，不重新生成成功素材 | 提交前后 task/batch/job ID |
| 成片 | 实际可解码 MP4、画幅/总时长与时间线相符，有可听音轨，关键动作未丢失 | 输出文件、时间线修订和审片记录 |

六轮发言指三场中的 2、2、2 次发言，不要求固定镜头或视频单元数量。对不同端点的多镜头、口型或声音一致性不能只凭样例文字认定通过。
