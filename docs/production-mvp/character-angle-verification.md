# 人物角度功能验证

日期：2026-11-04。范围：仅人物三视图＋正面特写，以及拆解/视频单元选择人物角度；场景和道具不增加多视角。原 ArcReel 未修改。

## 实现

- 默认人物模板为正面全身、右向90°侧面全身、背面全身、正面特写四格；保留自定义完整提示词。衍生模板遵循输入版式。
- 人物资产卡增加可调整矩形的本地裁切，逐角度确认保存为原角色子图，沿用上传与版本链，不调用模型。旧图可手动框选；不会假设旧图已是四格。
- 拆解/视频提示词选择器只改画面引用，不改说话人或台词。换装形态不被切回本体角度；同一人物角度与声音归属在真实附件声明中明确。
- 子图通过原请求投影与产物校验进入实际视频请求；父角色仍显示在本集资产列表，移除父角色会处理角度引用。
- 保存的角度图是作者确认的独立图片，原图更换后不会自动更新，界面提示重新裁切。场景/道具、供应商、队列、计费与剪辑逻辑沿用原实现。
