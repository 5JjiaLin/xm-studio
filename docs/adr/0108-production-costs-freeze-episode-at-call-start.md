# XM_Studio 单集制作成本冻结调用归属

XM_Studio 的 E2 要在成片页和单集管理页展示一集的累计制作成本，覆盖文本拆解、提示词、生图、生视频及重新抽卡。制作中不再要求用户查看报价，但原视频准入、时长档位、附件和重复提交检查继续执行。

复用 `api_calls` 原账本及结算快照，增加可空 `episode_id` 和 `generation_target`。任务入队时按明确单集参数或项目账本中唯一匹配的 script_file 保存 `billing_episode_id`，真实供应商调用发起时从同项目、同用户任务冻结归属。文本调用复用 worker 的任务认领上下文关联任务，不创建另一套执行上下文。任务去重沿用原任务归属，共享资产后续复用不产生调用；主动重做记入发起集。

历史行两个新增字段为空时，只从明确任务 payload / 当前账本精确脚本关联恢复读视图；不按资产名、条目编号前缀或第一集推测。新行的空 `generation_target` 表示已记录但无任务证据，不能被后续任务变更重新归属。已删除集和无法确认的记录单列为项目未归属成本。

只读接口 `GET /api/v1/projects/{project}/production/costs` 按当前用户查询最少账本字段，返回每集及项目未归属的金额、类型明细、调用数和重做子集。相同稳定目标（任务类型、资源类型、脚本、资源 ID）的后续真实调用记作重做/重试；它只是总费用的子集，不能再叠加。没有目标证据的历史调用不猜测重做次数。供应商重试在同一条账本行内合并时，沿用原调用记录粒度，不声称逐条展示底层 HTTP 次数。

金额只读冻结的 `cost_amount`，不按当前价格重算。包含失败但已记录费用的调用及未采用版本；pending 和未定价记录分别计数，金额只展示已知小计；不同币种不换算、不相加。查询、下载、复用和本地渲染不会开账。端点测试和助手调用不计入制作成本。

此决策仅替代 ADR 0053 在 XM_Studio 制作成本视图中的集归属口径；原 manifest 估算接口及其条目分配语义不改写。ADR 0076 的真实调用账本和 ADR 0100 的不可变价格快照继续有效。迁移只增加 nullable 列，保留全部历史数据。
