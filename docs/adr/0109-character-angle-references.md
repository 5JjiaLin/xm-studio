# 人物三视图加正面特写，分镜使用单张角度图

2026-11-04 用户限定：只加人物四视图与分镜角度选择，场景和道具多视角暂不做。本决策替代 ADR 0066 中角色三面板和不裁切的选择。

默认人物资产为正面全身、右向90°侧面全身、背面全身、正面面部特写四格。用户已有完整提示词不覆盖；旧图不自动重生。角色衍生守卫跟随输入版式，单张角度不被强制恢复为拼图。

四格不是模型的像素布局保证。人物卡允许用户调整百分比裁切框，逐角度确认并在本地裁切，不调用模型。复用角色 derivatives 与上传版本链，命名为视角-正面全身、视角-侧面全身、视角-背面全身、视角-正面特写。子图仍属于同一角色及声音，不把视角登记为新人物。与换装形态不同，选择器不会把换装/受伤等引用切回本体角度。

裁切图按作者确认的独立成品上传（ADR 0072）：主图替换后保留旧角度，需要用户重新裁切更新；界面明确说明，不宣称自动同步或自动过期。重复保存同一角度进入原版本链。上传失败保留已登记子项，下次重试先读登记状态，不重复创建。保存无图的子项不会进入可选角度列表。

拆解页和视频提示词页选择角度时只替换画面 mention，逐字保留说话人及台词；现有 @[角色/子图] 解析、预览、准入、实际请求和产物依据完成接线。没有可用子图时继续用原资产图。自定义完整视频正文不被覆盖，用户应核对机位描述与选图是否匹配；附件绑定仍由真实参考图生成。

提示词编写阶段按已登记角度与镜头需要选择引用，并说明位置、视线、起止状态。场景、道具与模型供应商配置不扩展。不新增队列、工作流、成本模型或独立角度管理页面。
