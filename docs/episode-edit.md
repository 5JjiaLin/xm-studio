# 单集剪辑：部署和交接

视频页片段全部就绪后，点「剪辑」，不用重新上传或填写剧本。XM 使用本集已选视频版本、剧本、已确认分镜、引用资产描述和成片规格。进度与结果都在成片页；预览后点「采用此版」才开放 MP4 下载与剪映交接。采用前若已有片段换版，需重剪；已采用的旧版不被覆盖。

## 运行条件

- OpenFilm 固定为 `0.4.1`。将其安装为 XM 后端的依赖，`XM_OPENFILM_DIR` 指向包含 `package.json`、`src`、`manual` 和 `studio/server` 的包目录，而非整个上游仓库。测试使用上游提交 `327ef4c86ceab07122a145c0d6d984045af7c295`。无需另启 Studio 或创建账号。
- 后端 `PATH` 上需有 Node.js >=22.2、FFmpeg 和 ffprobe。用与 OpenFilm 的 `playwright-core` 匹配的 Chromium，`PLAYWRIGHT_BROWSERS_PATH` 指向浏览器安装目录；`OPENFILM_LIBRARY_CACHE` 指向已预热 Whisper Small 及运行时文件的 OpenFilm 缓存。应用启动时通过环境变量或本机 `.env` 传入这些路径。
- 剪点使用 XM 已配置的、支持图像输入的复杂档文本模型。主动提交剪辑会将本集脚本、分镜、参考描述、视频抽帧及对白转写发给该模型；原始视频不上传。模型请求计入本集费用，不自动切模型或重提结果不明的旧调用。
- 「生成配乐」默认不勾选。要启用本机生成，配置 `XM_EDIT_MUSIC_PYTHON` 和 `XM_EDIT_MUSIC_CHECKPOINTS`；目前适配 Apple Silicon 上的 ACE-Step 1.5 Turbo。失败时保留原声并在结果中提示。音乐独立轨道保留，压低对白处音乐的包络烘焙在音乐副本，剪映中可独立调音量或替换音乐。
- 本机剪映交接复用 XM 已保存的草稿箱设置。剪映运行中时，按成片页提示退出剪映再继续；远程端可下载草稿包，但不会替浏览器所在电脑登记。

## 实现与恢复

`server/services/project/episode_edit.py` 复用单集 journal 与串行 render 车道，按素材基线去重。`lib/openfilm/` 调用上游抽帧、Whisper、渲染和剪映导出；上游 film Skill 与漫剧剪辑 Skill 共同用于剪点判断。同一 `film.html` 生成 MP4 和草稿，不由 XM 重新拼接。剪点保护对白，保留分镜顺序；无法自动修复的画面连续性问题可作为复看点呈现。

「继续剪辑」复用已确认的阶段结果。「重新剪辑」显式新建尝试，仅用于结果未知或结果不可用的失败。刷新不会提交新任务。成片采用按版本、文件摘要和素材快照核对；草稿交接不覆盖已登记的旧版本。

工程验收覆盖任务去重、素材换版后的确认拒绝、结果未知恢复、页面进度与采用，以及合成素材的真实本机渲染和临时剪映索引写入。合成样片的视觉模型使用测试桩，未向外部服务发送真实项目内容；不等同实际整集效果或剪映真机验证。
