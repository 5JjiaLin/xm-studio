# XM_Studio

本机短剧制作工具，围绕单集制作提供从剧本到成片的工作流程：

**项目 → 单集 → 剧本 → 拆解 → 资产 → 视频 → 成片**

项目与测试记录保存在本机。制作团队可在各自电脑上记录提示词、资产图片和视频单元的修改，并导出记录供离线汇总。
