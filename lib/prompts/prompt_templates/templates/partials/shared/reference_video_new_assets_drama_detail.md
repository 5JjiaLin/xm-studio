# 短剧资产描述补充规范（仅用于新启用的剧情策略，画风遵循项目设置）

本段只补足登记用 description 与设计补全 reason，不改变资产分类、引用、合并、跳过、衍生或正式登记规则。

- character 表示参与剧情的角色，不等同于人类。先按原文确定实际形态，再展开适用设计：人类使用下述人物细则；动物、魔兽写尺度、体态比例、头部与感官、肢体尾翼、毛羽鳞片等表面材质和配色；机械角色写轮廓尺度、结构关节、传感器、外壳材质与标识；无固定形体角色写可见轮廓、核心、层次、边缘及颜色透明度。不为凑齐人物细则给非人角色添加人脸、发型、衣服或直立姿态。reason 只记录原文依据与设计补全范围，不能代替 description 中的外观设计。

- 本策略明确授权完成美术设计：原文是剧情与已知外观的依据，不是外观细节的上限。本段的普通外观、装饰纹样补全规则优先于上文“信息少时不编造纹样”的一般规则。不得因原文没有写发型、肤色或年龄就留下空白或要求用户确认；除用户明确要求保留未定外观外，直接给出一套符合时代、世界观与角色气质的稳定设计，reason 标注哪些部分为“设计补全”，不将设计值声称为剧本事实。
- 人物 description 要有完整的可视化设计：①约数年龄与体态、肩腰比例；②脸型、眉骨眉形、眼形瞳色、鼻梁、唇形及下颌；③肤色及自然皮肤肌理；④发色、长度、分区与梳理方向；⑤服装的内外层、领型、肩腰剪裁、衣长、开合结构、颜色、面料与褶皱；⑥裤装、鞋履、手套等固定配饰的结构与材质；⑦原文明确的伤痕或束缚的位置、范围与外观。每项写具体形态，不用“精致五官”“普通发型”代替设计。人物四视图使用同一套外观，描述中不写临时表情动作、运镜或手提独立道具；临时持物与衣襟开合等变化在视频正文或必要衍生中表达。
- 例如原文只有“成年男性、宽肩、刀削脸、血红眼、黑色军大衣”时，可设计为：约35岁，宽肩厚胸、腰线收紧，修长棱角脸与清晰颧骨，眉骨略深、眉形平直，狭长血红双眼，高直鼻梁、薄唇与利落下颌；浅肤色保留细微毛孔，黑色短发向后梳理、发顶略蓬松；厚黑呢长军大衣采用挺立高领、双排银扣、加宽肩线与略收腰剪裁，下摆至小腿中段，配黑色修身军裤、齐腕哑光皮手套与方头皮鞋。示例仅说明细化程度，不能把该套外形复制给所有人物。原文明确的其他特征必须保留。
- 禁止借美术补全改变人物身份、血缘、剧情年龄身份（儿童不能改成年）、族裔设定或新增能力、伤势原因、剧情事件。无族裔依据时直接设计可见五官和肤色，不把外观推断写成国籍或族裔事实。形态差异只写在 derivative 的变化描述。
- 独立道具 description 必须能辨认物件形制和尺度，写物件轮廓、尺寸约数与单位、人体尺度参照、结构、材质、颜色、工艺和识别细节。箱体优先给长宽高；针、杆给总长和主体直径；容器给高度与最大直径。按形制选必要尺寸，不把不适用的长宽高设为必填。避免只写“破旧、精致、普通”等无法指导图像的评价词。
- 返回 JSON 前逐项检查所有 decision=register 的实体道具：description 必须实际包含数值及长度单位，不能只在 reason 声称已补尺寸。“掌心大小”“一掌长”等仅作辅助；符纸等薄片可写“约长9厘米、宽6厘米”，不强求厚度。补齐缺项后再输出，保持已拆好的单元、台词和其他资产不变。
- 原文未给尺寸、提手结构或装饰纹样时，直接给出符合剧情用途的一组合理设计：如手提木箱约长40厘米、宽25厘米、高25厘米，顶部一只深色皮革提手、旧木板拼缝与磨损铁包角；银色纹饰针约长8厘米、针杆直径2毫米，窄叶形针首、对称卷枝浅刻纹。具体设计随物件和世界观变化，不把示例当通用外形，不新增法力、内容物或特殊剧情机关；在 reason 标注尺寸和结构纹样的“设计补全”。
- description 只放能直接画出来的视觉内容，不出现“原文未交代”“需待确认”“具体形制待确认”“未知”等占位说明。reason 仅说明原文依据和设计补全范围。不要在 reason 写面板、白底、图片比例等出图指令；人物四视图及资产图固定布局仍由系统模板负责，描述不得替换布局。
- 场景沿用现有场景规范。本补充不要求场景资产改为多视角，不生成视频镜头，也不添加独立道具只为增加画面细节。
