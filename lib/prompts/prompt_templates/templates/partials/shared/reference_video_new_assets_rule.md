# 本集新增资产（new_assets）

先按登记名、别名与外观匹配已有资产；同一物件的别称复用已有资产。没有新增资产时输出 `[]`。

道具按以下顺序判断：已有资产复用 → 场景内建筑与陈设、角色服装与附属物 → 普通文字物件 → 必须固定独立视觉形制的道具。只因出现、多次提及、被触碰或搬动，不足以独立登记。

独立道具需要具体依据：关键特写或视觉揭示；掉落、交接、打开、损坏等行为需要看清其特定形制；贯穿连续镜头、需要保持同一外形及持物关系的物件；或用户指定独立参考图。普通外形的物件也可能需要跨镜头保持一致，不能以「不是特殊物件」排除。`reason` 说明具体镜头用途与连续性依据。不设固定数量上限。

场景图描述稳定空间、柱、台、灯等陈设；不为同一场景的每个陈设再拆道具。服饰及持续佩戴的束缚物归人物当前外观。手链、脚链、镣铐等在人物身上持续存在、没有独立拿取、交接、解锁或形制特写需求时，作为一个完整人物着装／束缚形态，不再重复建立铁链道具。已有本体时使用 `derivative`，以本体为 `target`，形态名如「束缚形态」，`description` 写手腕、脚踝的束缚与服装变化；首次出现且只有这一外观的角色，在该人物的 `register.description` 中完整写入服饰与束缚状态，作为一个人物资产；确有多种必要外观时再声明本体及衍生，不能重复登记人物身份。视觉引用写 `@[人物/束缚形态]`，对白说话人仍写 `@[人物]{对白}`。只有剧情确需独立操作或展示束缚物时才独立登记道具。随身木箱等按本集实际镜头用途判断，不按名称一概排除，也不塞进角色固定身份图。例如埃利亚斯从开场到冲突后始终拎着同一只破旧木箱，需要保持箱体外形和持物关系时，将木箱登记为道具，在它可见的单元中引用，并说明哪只手持有、是否落地及末态；不得为补状态而编造原文没有的交接。针落地后成为凝视焦点等关键视觉物件也可独立。无需独立参考图的物件仍须在视频正文保留其可见外观、动作、持物、接触关系和对白；不登记不等于不出镜，不能令箱子消失、铁链解开或新增处置情节。

需要引用的新角色、场景及必要独立道具写原文称呼并列入 `new_assets`，同类同名只列一项。每项填写 `type`、`name`、`decision`、`reason`：

- `register`：登记新资产；`description` 必须非空，按原文写角色长相服装、场景空间陈设或独立道具的形制材质，作为完整生图提示词的内容依据。信息少时仍保留已知特征，不编造纹样、内部物品或特殊能力；其他称呼写 `aliases`，正式登记名可填 `asset_name`。
- `merge`：同一资产的别称，`target` 为同类已有登记名或本次新增称呼；不能把 prop 合并到 scene。场景陈设直接写入场景与正文。
- `derivative`：仅角色的另一套必要外观；`target` 为本体，`asset_name` 为形态名，`description` 仅写变化。不自动为每种临时持物扩增形态。
- `skip`：不需要独立图，仅保留普通文字。确认后去除视觉引用，不删除动作、台词或说话人。

`name`、`asset_name` 都是单个名字。已登记描述保持原样；`merge`、`skip` 的 `description` 留空。取舍只影响本次建议，不删除已有公共资产或历史素材。

输出前核对 `decision`、`reason`、`description` 一致：决定登记的项不能留下空描述，理由也不能写「仅普通文字保留」；决定 `skip` 的项不能要求依靠该项独立参考图维持外形。
