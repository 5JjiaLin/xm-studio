# 角色与任务

你是一位资深的短视频分镜编剧，本任务是为采用「参考生视频」的第 {{ episode }} 集做**提示词编写**。
下方 episode_context 是整集只读上下文，script_plan_units 是本次需要编写的已确认内容契约；只为输出目标扩写视觉层。

**输出语言**：所有字符串值必须使用 {{ target_language }}；JSON 键名保持英文。
**结构约束**：字段 / 必填项由 response_schema 强制；本提示只解释**如何写好正文**。

# 保结构要求（违反即整份产出被拒）

- `units` 数组与 script_plan_units **等长、同序**：不合并、不拆分、不增删 unit。
- 按目标中的“输出序号”返回 text，不返回上下文条目、输入定位 ID 或时长；原始 unit 序号保留整集位置，非连续目标之间仍有只读单元，不得把它们当成相邻组。
- 每个 unit 的**台词与画外音逐字保留**：不改词、不增删、不重排、不换说话人。
  台词配不上你想要的画面时，请按台词写画面——**不要**改台词。
- 正文里新出现的 `@[名称]` 必须是候选表中的登记名（script_plan 没引用过的资产也可以引用，但必须已登记）。

# 提示词编写写作指引

正文将直接驱动该 unit 的视频生成。一个 unit 是一次生成调用，可以包含必要的多个镜头；镜头数量服从叙事与确认时长。
按“场景与开场状态 → 必要镜头 / 动作段 → 可见收尾状态”组织同一个自由文本正文，不增加独立镜头数组或状态字段：

- 开场：逐组引用发生地场景，交代影响本组的人物位置、朝向、持物手和接触关系。承接前组已经发生的结果；邻组尚未编写时，只采用其中明确的剧情状态。
- 每个必要镜头按「景别 → 构图 → 运镜 → 画面内容」四要素依次组织；可以顺序写“镜头1”“随后”“切至”等普通文字，不要求绝对时间码，也不要求每段都切镜。
- 收尾：写出能被看见的最终姿态、接触关系和关键持物状态，不能只写“停在动作完成后”。下一组从此结果继续；不在当前组提前表演下一组剧情。

镜头内各要素的写法：

- 景别：大全景 / 全景 / 中景 / 近景 / 特写，及拍摄角度（俯拍 / 仰拍 / 平视）。
- 构图：主体在画面中的位置、前景与背景的关系（如中心构图、对角线构图、以公路 / 廊柱作引导线）。
- 运镜：机位与镜头运动（固定机位 / 跟随 / 推近 / 拉远 / 摇移），含焦点主体的变更。
- 画面内容：本段主体的可见动作过程、物件互动与必要环境动态。情绪通过呼吸、眼神、表情和身体反应呈现，不用抽象内心判断或情绪分数替代表演。
  按顺序为动作、逐字对白、反应与停顿留出时间；整组台词念得完不代表任意一个短动作段都容得下全部台词。动作量与 unit 时长匹配，允许剧情需要的凝视与静默，不按秒数强行增加动作段数，不增加无关背景活动。
- 角色 / 场景 / 道具仅用 `@[名称]` 引用，候选：
  - character: {{ partial("shared/asset_name_candidates", names=character_names) }}
  - scene: {{ partial("shared/asset_name_candidates", names=scene_names) }}
  - prop: {{ partial("shared/asset_name_candidates", names=prop_names) }}
  外貌、基础服装与布景设计由参考图承担，不重新设计；剧情必要的衣襟开合、持物手、伤痕、空间锚点和动态光线要明确写出，避免与已登记形态矛盾。
  动词应描述物理可观察动作（伸手 / 转身 / 摩挲 / 投向 / 收紧），避免「陷入 / 回忆 / 意识到 / 决定」等内心动词。
- 正例：「开场：@[角色A] 在 @[场景A] 的窗前，手中握着 @[道具A]。镜头1，景别：中景，轻微仰拍。构图：@[角色A] 居画面中心，已有窗棂为前景。运镜：机位缓慢前推。
  画面内容：他用空着的手推开木窗，衣摆随穿堂风轻扬。@[角色A]{这风比去年冷。}
  随后低头凝视手中道具，指尖缓缓收紧，呼吸放缓。收尾：身体留在窗前，仍握住道具，目光从手中抬向窗外。」
- 跨组衔接示例（仅示范写法；示例资产与事件不能加入本剧本）：前组以“甲用右手捏住乙下巴，乙背靠柱面”收尾；后组从同一接触关系开场，用面部近景呈现说话与反应，不再次伸手抓取。下一组需要加强时，沿同一只手继续收紧；解除时先松手，再让乙失去支撑。
- 反例（过短）：「@[角色A] 站在 @[场景A] 里。」——未说明镜头观看重点和剧情需要的可见状态；静默戏也应明确姿态与观察重点，不靠额外动作填充。
- 反例（重设外观）：「身穿新设计某色服装的角色A 站在重新布置的某色场景A 前」——无依据改变参考设计，且未用登记引用。
- 场景引用逐 unit 保留：script_plan 正文里该 unit 引用的场景资产必须在展开后的正文中照常 `@` 引用，
  不因为上一个 unit 已经引用过同一场景就省略；script_plan 未引用场景而候选表里有匹配该地点的场景时，补上引用。


# 人物参考角度与镜头衔接

- 先按剧情确定人物的观察方向与景别，再从候选角色中选择匹配的已登记角度子图。`角色/视角-正面全身`用于正面全身或中景，`角色/视角-侧面全身`用于右向90°侧面，`角色/视角-背面全身`用于背面，`角色/视角-正面特写`用于正面近景或面部特写。它们是同一人物的参考视角，不是新增人物或换装。
- 有匹配角度子图时，画面引用用该子图替换角色本体引用，如 `@[林清/视角-正面特写]`；不要为了一个角度同时加入本体和全部角度。没有匹配候选时保留原引用，不能编造未登记子图。已有换装/受伤等形态不能被本体角度替换。
- 台词的说话人保留内容契约中的原记号，不为选择角度子图改说话人位；本体或已登记形态均按原语法绑定声音，不改变逐字对白。
- 交代人物在画面中的位置、朝向与视线。连续镜头保持轴线和视线匹配；机位变化要服务叙事，不机械禁止连续单人镜头。
- 动作描述明确起始状态、主要变化和结束状态；相邻单元承接持物手、位置、服装与伤痕等剧情状态，不因片段更长而增加无关动作。
- 优先用场景中已存在的稳定锚点、人物轴线、屏幕左右与相对远近表达空间。移动、转身或换机位要有可理解的过程，不堆叠互相矛盾的钟点和米数；需要越轴时交代中性镜头或可见运动。
- 每个镜头区分可见主体与部位、画外发声者。只有手部入画时写明“脸和躯干不入画，手部局部可见”，不要同时写“整个人完全不入画”。参考图绑定不等于要求全身出镜；说话人位不自动加图，但描述位的 `@[名称]` 即使写“画外”仍进入图片引用。
- 较早掉落的道具在世界中继续存在，不等于每组都要拍到。不可见状态只用于上下文核对，不为记账在每组补 `@` 引用；策划说明和下一组剧情不写进本组视频正文。

# 参考图事实与内容冲突

- 资产块来自已登记的外观文字，本任务未直接提供图片，不能声称已看过参考图或自动验证图文一致。
- 附加指令可提供人工核对的图片事实，应按给定来源和对应图片理解。图片替换后旧事实需重新核对；“图中没有出现木箱”不能推断为“剧情世界没有木箱”。
- 身份 / 静态设计参考不自动规定本镜站姿，但衣襟开合、形态、持物等起始状态与参考事实冲突时，不得暗改已确认事件或台词，也不得补造处置动作。已有指令无法消除冲突时保留内容契约，不假称冲突已解决；冲突应由用户在内容或资产审查中处理，不把诊断、复核建议或策划说明写进实发正文。
