# 漫剧初剪

1. 用集级快照建立关键事件顺序、说话人和必须保留的动作。剧本只说明意图；视频与实际对白用于验证。候选先核对媒体哈希；没有不同版本就明确记录，不假设重抽。
2. 先看每段接触表，疑点再看密集帧；将前段最后 1–2 秒、后段最初 1–2 秒并排，记人物相对位置、朝向、道具数量与持有人。标出「源内穿帮」「跨镜跳变」「重复但有叙事用途」和置信度，不以自动黑闪检测代替语义审核。
3. 先保护实际实词、动作起止和门响等叙事声。ASR cue 只是粗定位；词时间有疑点就对照音频能量、嘴型或听审。裁静持只在出入状态匹配且留有对白前后余量时采用：写原片入出点、时间戳证据、预期收益；无法剪掉且没有候选则标记保留或补镜，不能用转场假装修复。始终保留整段原片。
4. 生成剪点后保留原顺序，按目标 fps 确定性验无空隙、无重叠；从源 ASR 重映射字幕、按实际对白重建压低窗口。配乐对照沿用同一首，保留门响和原声，输出独立音乐、原始音频、可编辑音量和淡入淡出。若压低只烘焙到音乐副本，明确写出该限制。
5. 复看变更切口与所有未解决问题，核验画面/字幕/音频、剪映原片和轨道。对照使用相同模型、素材和输出规格，分开汇报真实改动、仍需补镜的问题和待人工听审；禁止把时长缩短等同于质量提升。
